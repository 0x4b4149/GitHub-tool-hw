## Q: 按照第一步把畫面做出來。做完後請指出來給我看：程式碼裡的哪一行是負責『記住』我打的名字的？那一行長什麼樣子？

## A:
```
🔍 哪一行負責「記住」你打的名字？
在 src/App.vue 檔案裡，大約是第 27 行：
const 名字盒子 = ref('')
這一行就像一個「空盒子」，一開始是空的。當你打字的時候，輸入框會把字放進這個盒子裡面，然後它就會「記住」你打的字。
---
完整程式碼位置
src/App.vue
├── 第 18 行：<input v-model="名字盒子">  ← 這裡讓盒子跟輸入框連在一起
├── 第 27 行：const 名字盒子 = ref('')  ← 這裡是真正記住的盒子
```

## Q: fetch 我沒看到你是用 get 還是 post 或是其他的 http method，參數你是怎麼代入的?

## A: 
```
好觀察！你發現了一個重點：
---
🚀 fetch 預設就是 GET
就像打電話一樣：
- GET = 問：「幫我查一下這個名字的資料」
- POST = 說：「幫我新增一筆資料」
因為我們只是「去問 GitHub 資料」，不是要「新增資料」，所以用預設的 GET 就可以了！
---
📝 參數怎麼代入？
在網址後面加上去，就像寄信寫在信封上一樣：
fetch('https://api.github.com/users/' + 名字盒子.value)
如果 你打 octocat，那麼網址就會變成：
https://api.github.com/users/octocat
這就像跟 GitHub 說：「幫我找 octocat 這個人的資料！」
---
比喻整理
HTTP 方法	比喻
GET	問問題（查資料）
POST	寄包裹（新增資料）
PUT	換東西（更新資料）
DELETE	刪掉（刪除資料）
---
我們這個功能只需要「問問題」，所以用 GET 就夠了！還有其他想知道的嗎？
```
