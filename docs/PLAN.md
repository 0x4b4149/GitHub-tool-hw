# GitHub 偵察機 - 開發計畫

## 專案目標
做一個網頁，可以搜尋 GitHub 使用者並顯示他們的頭像。

## 運作流程（像去圖書館借書）

1. **輸入框** - 你在紙上寫下要找的人的名字（就像寫借書單）
2. **按鈕** - 你把紙交給老師（按鈕就像「幫我找！」的送信員）
3. **網頁** - 老師打電話給圖書館（網頁幫你傳話）
4. **GitHub API** - 圖書館管理員在電腦裡搜尋（像在電腦找資料）
5. **資料回傳** - 管理員找到照片，寄回來給你
6. **照片出現** - 就像收到包裹，開心打開看到照片！

## 簡單版（用小朋友的話）
你寫名字 → 按鈕幫你傳話 → 網頁打電話問 GitHub → 
GitHub 找到資料 → 寄回來 → 網頁把照片變出來給你看
